# Sri Ram M | Developer Portfolio

Welcome to my personal developer portfolio! This is a modern, highly interactive web application designed to showcase my journey, technical expertise, and creative projects as an aspiring Full-Stack Developer, UI/UX Designer, and Python Developer.

**Live Deployment:** Hosted on [Render](https://render.com)

---

## 🎨 Appearance & UI/UX Design

This portfolio is engineered with a heavy focus on modern web aesthetics, smooth interactions, and a premium user experience:

* **Glassmorphism Aesthetics:** Utilizes translucent backgrounds, frosted glass backdrop blurs, and subtle glowing borders to create a deep, layered interface.
* **Fluid Animations:** Powered by Framer Motion and GSAP, featuring scroll-triggered reveals, sticky-stacking cards, seamless marquee carousels, and an interactive 3D card-swap mechanic.
* **Responsive Architecture:** Meticulously tailored for all screen sizes. Features adapt intelligently—from immersive Macbook-style scroll effects on large desktops to clean, accessible vertical flows on mobile devices.
* **Dynamic Theming:** Fully supports both Dark and Light modes with seamless, animated transitions across the entire color palette.
* **Interactive Elements:** Includes a custom animated profile frame that reacts to user interactions, glowing hover states, and dynamic timelines.

---

## 📂 Inside the Portfolio

The portfolio is structured to provide a comprehensive view of my professional and academic background:

* **Hero Section:** A dynamic introduction featuring an interactive, glowing profile frame and a rotating typography display of my core roles.
* **Tech Stack Marquee:** An infinite, seamless scrolling banner highlighting my primary technologies (React, Next.js, Python, AI, MongoDB, etc.).
* **About & Skills:** A "Bento-box" grid layout categorizing my expertise across Frontend, Backend, AI & Data Architecture, and Workflow Tools.
* **Featured Work (Projects):** A sticky-scrolling showcase of my major projects, detailing features, tech stacks, and providing direct links to source code and live demos.
* **Education & Experience:** Clean, vertical animated timelines detailing my academic journey at the Coimbatore Institute of Engineering and Technology and professional internships.
* **Achievements:** A unique, interactive "Card Swap" interface highlighting my competitive milestones, including hackathon victories (TECHNOVIBES, CRYPTERA) and NPTEL certifications.
* **Contact & Resume:** A glassmorphic terminal providing direct communication links (Email, Phone, LinkedIn, GitHub) alongside a stylized resume preview and download option.

## 🛠️ Tools & Technologies

This project was built from the ground up using a modern, performance-driven tech stack:

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** 
  * [Framer Motion](https://www.framer.com/motion/) (UI interactions and scroll effects)
  * [GSAP](https://gsap.com/) (Complex timeline animations for the Card Swap component)
* **Icons:** [Lucide React](https://lucide.dev/) & Custom SVGs
* **Deployment:** [Render](https://render.com/)
